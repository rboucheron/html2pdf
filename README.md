# PDF to HTML Converter

Un script Python simple et efficace pour convertir des fichiers PDF en documents HTML tout en préservant la structure du texte et la mise en page.

---

## 📌 Fonctionnalités

* 📄 **Conversion rapide** : Transforme n'importe quel fichier PDF en page HTML.
* 🛠️ **Installation automatique** : Détecte et installe automatiquement les dépendances requises au lancement.
* 🎯 **Utilisation simple** : Interface en ligne de commande interactive.

---

## 📋 Prérequis

* **Python 3.8+** doit être installé sur votre système.
